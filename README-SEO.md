# SEO-контент для ОПТ МЕБЕЛЬ ЮГ

## Что предлагает автор видео

Разобран файл 2687502929622999363.mp4 длительностью 85,63 секунды. Вывод основан на просмотре кадров и встроенных субтитров; это пересказ, не дословная аудиорасшифровка.

- 0–25 с: автор обещает рост видимости в Яндексе благодаря тематической карте сайта.
- 25–38 с: предлагает попросить Claude или ChatGPT составить 25 вопросов потенциальных клиентов, сгруппировать их и придумать заголовки статей. Пример в ролике — ландшафтный дизайн в Санкт-Петербурге.
- 38–48 с: каждому вопросу соответствует статья, раскрывающая тему бизнеса.
- 48–71 с: предлагает автоматизировать подготовку и публикацию по расписанию, подключив сайт. Упоминаются и ежедневные, и еженедельные публикации; конкретная техническая интеграция в видео не показана.
- 71–85 с: связывает полезный тематический контент с поисковой видимостью и предлагает получить его гайд.

Это система тематического SEO-контента. Для мебельного B2B она должна приводить из поиска к полезному ответу, затем к запросу прайса или расчёта. Гарантии первой страницы Яндекса из ролика принимать нельзя. Тематическая карта здесь — редакционный план, а sitemap.xml — отдельный технический файл для поискового робота.

## Что проверено в инфраструктуре

26 сентября 2026 года сайт https://www.optmebelug.ru/ доступен, описывает контрактное производство, работу с ЮЛ/ИП, заказ от 300 000 ₽, проектирование, упаковку и логистику. Эти условия использованы в стартовых материалах. Обещания доходности, экономии и фиксированных сроков не переносились в статьи.

Актуальный репозиторий — `killupdate/OptMebelUg_New`. Он активен; изменения интегрированы в отдельную ветку `feat/b2b-knowledge-base` поверх commit `82dfa7a` от 26 сентября 2026 года.

Стек: Next.js 16.1.1, React 19.2.3, TypeScript, Vercel. Вебхук Next.js пересылает события Telegram в PHP-бот на Spaceweb. Репозиторий также содержит Telegram Mini App для отправки заявки через `/telegram-order`; новая база знаний не изменяет её форму и API. Доступная локальная версия PHP-бота отвечает меню на `/start` с параметром, но не сохраняет источник. Фактический код на сервере в этой задаче не проверялся.

## Архитектура

Поисковые вопросы → очередь тем → Codex готовит черновик → проверка фактов → контент в Git → сборка Next.js → Vercel → индексирование Яндексом → читатель → Telegram → запрос прайса / квалифицированная заявка.

| Компонент | Первый этап | Дальнейшее развитие |
|---|---|---|
| Темы | content/topics.json, 25 вопросов в 5 группах | Проверка спроса в Wordstat и Вебмастере |
| Статьи | content/articles.json, структурированные блоки | Дополнение кейсами, фото и ответами технолога |
| Сайт | /knowledge и /knowledge/[slug], статическая генерация | Разделение по группам при росте материалов |
| SEO | title, description, canonical, Open Graph, Article/BreadcrumbList, sitemap, robots | Вебмастер, контроль индексации и запросов |
| Подготовка контента | Локальное задание для Codex через content:prepare | Планировщик Codex готовит 1 черновик в неделю |
| Публикация | Проверка → изменение в активном GitHub → Vercel | Автосборка после принятия изменения |
| Telegram | Ссылки с start=seo_kbNN | Запись источника в существующую MySQL бота |
| Измерение | Пока не подключено | Метрика: переходы в бот; бот: обращения и запросы; учёт договоров |

Для первого этапа новая CMS и новая база данных не нужны. JSON не исполняет код, тексты выводятся как обычные React-строки. Черновики со статусом draft исключены из списка статей и маршрутов; ready означает включение в следующую сборку. Доступ к редактированию регулируется GitHub.

## Что уже реализовано

1. Адаптивный раздел «База знаний» и ссылка на него в подвале главной страницы.
2. Три материала с чек-листами, содержанием и перелинковкой: запуск СТМ, ТЗ на расчёт партии, подготовка мебели для маркетплейсов.
3. Метаданные страниц, canonical, структурированные данные, sitemap.xml и robots.txt.
4. Метки seo_kb01–seo_kb03 в ссылках на @OptMebelUg_GivMyPR_Bot. Это заготовка атрибуции, не работающая аналитика заявок.
5. Очередь из 25 тем. Частотность и конкурентность не измерены.
6. Команда content:prepare выбирает следующую тему и создаёт задание для Codex. Уже создано drafts/kb04.md. Повторный запуск не перезаписывает файл; следующая тема выбирается автоматически. Генерация текста и публикация по расписанию пока не реализованы.
7. Команда content:check проверяет адреса, связи, поля статей и формат меток.

## Последовательность запуска

1. Проверить изменения в ветке `feat/b2b-knowledge-base` репозитория `killupdate/OptMebelUg_New` и убедиться, что этот репозиторий подключён к нужному проекту Vercel.
2. Проверить три стартовые статьи со стороны производства. Добавить реальные фото, пример спецификации или кейс там, где доступны материалы. Сверить коммерческие условия.
3. Запустить проверки и preview-сборку Vercel. Проверить главную, раздел, все статьи, 404, sitemap и выдачу прайса ботом с тестовым пользователем.
4. Опубликовать раздел. Передать sitemap.xml в Яндекс Вебмастер, проверить индексирование. robots.txt не является защитой административной страницы — её доступ управляется отдельно.
5. На Spaceweb добавить сохранение допустимого /start seo_kbNN: first_source, last_source и время; повторный /start не должен затирать первый источник. Привязать источник к запросу прайса и заявке, исключить дубли по update_id. Проверить обычный /start, неизвестную метку, повторное событие и повторный визит.
6. Подключить события Метрики для переходов в Telegram. Различать клик, запуск бота, запрос прайса, квалифицированную заявку и договор; клик не считать заявкой.
7. Проверить карту тем по спросу и реальным вопросам клиентов. Объединить пересекающиеся запросы. Начать с одного полезного материала в неделю — это рабочая гипотеза, а не требование поисковика.
8. Настроить планировщик Codex: выбрать следующую тему, подготовить черновик и изменение в Git, выполнить проверки. Публикацию включать после проверки фактов; расписание само по себе не даёт доступа к сайту.
9. После накопления данных сравнивать группы по показам, переходам, запросам прайса и качеству заявок. Расширять темы, которые приводят подходящих B2B-клиентов. До появления данных срок окупаемости не прогнозировать.

## Применение

Архив optmebelug-seo-starter.zip содержит изменённые и новые файлы, README-SEO.md и патч относительно `killupdate/OptMebelUg_New`, но не полный репозиторий, зависимости или секреты. Для ручного применения в другой чистой копии:

```sh
git apply --check optmebelug-seo.patch
git apply optmebelug-seo.patch
npm ci
npm run content:check
npm run build -- --webpack
npm run start
```

Для следующего редакционного задания: `npm run content:prepare`. Можно явно указать тему: `npm run content:prepare -- kb05`. Это создаёт файл задания, который выполняется Codex отдельно. Нужен Node.js 22+ для скриптов.
